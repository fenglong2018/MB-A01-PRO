# KEY

四路 IO：EXTI 叫醒并禁该脚中断 → key 线程 10ms 积分滤波。确认有效后中断保持关，只轮询；确认无效或放弃毛刺沿才开回中断。

> **变更记录（2026-08-26）**  
> 四路统一：关中断 + 轮询。USB/SIM/FALL 有效 +1、无效 −1。USB 插入 **8** 拍、拔出 24 拍；SIM/FALL 认定 16、撤销 24。SOS 按下积分；松手连续 8 拍才确认短按/rearm。  
>
> **变更记录（2026-08-25）**  
> 上电/STOP2：USB、SIM 先滤波当前电平（已插着没有沿）。上电只补报插入，不报 USB_OUT。  
> SOS 短按 24 次（≈240ms）、长按 240 次（≈2.4s）。
>
> **变更记录（2026-08-24）**  
> 滤波期间 `pm_lock`。
>
> **变更记录（2026-08-21）**  
> STOP2 唤醒锁存 SOS/FALL 电平；叫醒那次 SOS 只认长按。
